PUBLICAÇÃO NO GITHUB PAGES
1. Faça backup do repositório antes de substituir qualquer arquivo.
2. Extraia o ZIP completo.
3. Envie os arquivos para a raiz da branch publicada no GitHub Pages.
4. Mantenha os nomes dos arquivos locais exatamente como estão.
5. Faça commit e aguarde a atualização do GitHub Pages.
