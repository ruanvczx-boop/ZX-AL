# Presente da Laura — atualização incremental

Este pacote foi preparado sobre o `index.html` enviado, preservando as seções e os textos existentes e ajustando referências de imagens e a seção de veículos.

## Publicação no GitHub Pages

1. Faça backup do repositório atual.
2. Extraia este ZIP.
3. Copie o conteúdo da pasta `presente-laura-atualizado` para a raiz do repositório, mantendo a estrutura de pastas.
4. Faça commit e push para a branch/pasta configurada no GitHub Pages.
5. Abra o endereço publicado e teste em celular e computador.

O arquivo `index.html` é o ponto de entrada. As fotografias originais recebidas também estão preservadas em `assets/` e há cópias com os nomes esperados pelo HTML na raiz.

## Itens pendentes — não foram simulados

- **Trilha ambiente de piano:** o arquivo `trilha-original.wav` não veio entre os arquivos enviados. O botão fica desativado e identificado como pendente, em vez de fingir que toca.
- **Dodge Charger 1970:** não foi localizada, nesta etapa, uma gravação identificada e com licença suficientemente verificável. O cartão informa que não há áudio associado.
- **Moto esportiva preta adicional:** o modelo não foi confirmado pela imagem. Não foi inventado um nome nem associado o som de outra moto.
- **Yamaha R15:** usa a gravação incorporada da publicação original do TMCBlog; exige internet e o player externo pode depender de disponibilidade/região.
- **Mazda RX-7, Toyota Supra A80 e Nissan Skyline R34:** usam links de áudio do Wikimedia Commons, descritos nas páginas de crédito. A reprodução exige internet.

## Observação importante sobre escopo

O material recebido nesta conversa continha um `index.html` e fotografias JPG. Não continha o ZIP completo do repositório, o arquivo original de piano, fontes locais, ou outros arquivos não referenciados diretamente no HTML. Portanto, este pacote é uma atualização do material efetivamente enviado — não uma cópia garantida de todos os arquivos atualmente existentes no repositório remoto.
